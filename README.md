# Pandas Data Structures

A structured technical reference covering **Pandas** core data structures, memory attributes, indexing patterns, and data transformation workflows in Python.

## Repository Contents

* **`01_series_architecture_and_inspection.ipynb`** — Constructing 1D labeled Series, inspecting underlying NumPy arrays and index objects (`.values`, `.index`, `.dtype`), and running distribution checks (`.value_counts()`).

## Tech Stack

* **Language:** Python 3
* **Library:** Pandas, NumPy
* **Environment:** Google Colab / Jupyter Notebook
